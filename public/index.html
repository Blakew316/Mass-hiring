        How it works

        1. Hire a candidate from the Pipeline tab, or fill in the form directly.
        2. Each document is generated as a personalized PDF — use Preview to check any of them first.
        3. One click emails the complete packet and files copies on the employee's BambooHR record.

        The documents are the company's own PDFs, published with the paperwork portal. The new hire reads each one in full, signs it there, and every signed copy carries an e-signature certificate.

            Mac relay

            checking…
            Setting it up on the Mac — three steps
            1. Generate a relay token below and copy it.
            2. On the Mac: cd Mass-hiring/relay && ./install.sh, paste the token into the config it creates, then run it again.
            3. Grant the two macOS permissions it asks for: Automation, so it can tell Messages to send, and Full Disk Access, so it can read delivery receipts, read receipts and replies.

            Without Automation nothing sends; without Full Disk Access texts go out but nothing comes back. Full instructions are in relay/README.md.

            A separate secret from your dashboard password. It unlocks the relay routes and nothing else.

            Pace & hours

            Up to 100. Above that, Apple bans accounts.
            The wait is randomised between the two.
            A fixed interval is the clearest bot signal there is.

              Set the admin password first

              This site is public, and the app can send email from your account, so it won't run until an admin password is set. It is what lets you create and delete teams — each team then signs in with a PIN of its own.

              1. Netlify → Project configuration → Environment variables → Add a variable (called “Site configuration” in the older UI)
              2. Key APP_PASSWORD, value = a strong password → Save
              3. Deploys → Trigger deploy → Deploy site, then reload this page
              4. Sign in, or use Start a new team on the sign-in screen
