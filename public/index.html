    Gmail App Password

    easy alternative

    No Google Cloud setup needed: create an App Password at myaccount.google.com/apppasswords and emails send from your work Gmail over SMTP. Note: Gmail does not attach your signature to SMTP sends — connect Google (left) if you want it included.

    Calendly

    When someone books, their card flips to “Booked” and your phone gets a push. Requires this app to be reachable at a public URL.

    Phone notifications

    Install the free ntfy app (App Store / Play Store), subscribe to a topic of your choosing, and enter the same topic here.

    Pick something hard to guess — anyone who knows the topic name can see its notifications.

    This site is public, and the app can send email from your account, so it won't run until a password is set.

    1. Netlify → Project configuration → Environment variables → Add a variable (called “Site configuration” in the older UI)
    2. Key APP_PASSWORD, value = a strong password → Save
    3. Deploys → Trigger deploy → Deploy site, then reload this page
